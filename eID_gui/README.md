# Legacy eID GUI assets

The old Python 2 GUI source and build definitions were removed from this branch
because no license grant was found for that standalone component. Its original
AUTHORS file and image assets are preserved unchanged as requested by the owner
for this code-only cleanup. No new license is asserted for those assets.

See [the code license review](../LICENSE_REVIEW.md). This directory is not a
supported application and is excluded from the F-Droid source build.
